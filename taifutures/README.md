# 台指期 (TX) 日盤紀錄系統

一個用 Go 寫的小型網頁工具，每天自動抓取**台指期貨 (TX) 日盤（一般交易時段）**的行情，
並紀錄與計算每日的：

| 指標 | 計算方式 |
| --- | --- |
| **振幅** | 點數 = 最高 − 最低；百分比 = (最高 − 最低) ÷ 昨收 × 100% |
| **跳空** | 點數 = 開盤 − 昨收；百分比 = (開盤 − 昨收) ÷ 昨收 × 100% |
| **漲跌幅** | 點數 = 收盤 − 昨收；百分比 = (收盤 − 昨收) ÷ 昨收 × 100% |

資料來源為**台灣期貨交易所 (TAIFEX)** 官方「每日交易行情下載」，免費且免金鑰。
每個交易日會自動挑選**成交量最大的近月主力合約**作為當日紀錄。

## 執行

```bash
cd taifutures
go run .            # 預設監聽 :8080，資料存於 records.json
# 或自訂：
go run . -addr :9000 -data /path/to/records.json
```

開瀏覽器進入 <http://localhost:8080>：

- **自動抓取期交所資料**：選日期區間（預設今日）按「抓取 / 更新」。
  假日或尚未收盤會顯示查無資料。
- **手動新增 / 修正**：直接輸入 OHLC 與昨收，用於補資料或修正。
- **匯出 CSV**：下載含所有計算指標的表格（UTF-8 BOM，Excel 可直接開）。

資料以日期為唯一鍵，重複抓取同一天會覆蓋更新，不會產生重複列。

## 編譯成單一執行檔

```bash
go build -o taifut .
./taifut
```

## 網路需求 ⚠️

「自動抓取」需要能連線到 `https://www.taifex.com.tw`。
本專案在 Claude Code 雲端開發環境中開發，該環境的網路 allowlist **僅放行
`github.com` 與 `proxy.golang.org`**，因此在雲端環境內無法實際連到期交所，
自動抓取會回報連線失敗——這是預期行為。請在**你自己的電腦**上執行即可正常抓取。

解析與計算邏輯已用離線樣本以單元測試驗證：

```bash
go test ./...
```

## 設計說明

- `昨收`直接由期交所提供的「漲跌價」回推（昨收 = 收盤 − 漲跌價），
  因此在合約換月日仍以同一合約為基準，跳空 / 漲跌計算正確。
- CSV 解析採**表頭關鍵字對應**而非固定欄位位置，能容忍期交所欄位順序微調。
- 期交所 CSV 為 Big5 編碼，程式會自動轉成 UTF-8。
